Privacy

Policy version 12, updated 2026-11-21.

The launcher needs no account and has no developer-operated server. If an update source is configured, updates are downloaded from GitHub. It contains no advertising, analytics or crash-upload libraries. This page describes what stays on the TV and what goes over the network.

Stored on the device

Tile order, folders, hidden apps, profiles, the selected profile, screen-saver settings, language and content preferences are kept locally in app storage. The launcher also keeps a small amount of local discovery data: which apps you launched, favorite and hidden recommendation cards, and which cards were already shown. That data is used only to arrange this launcher.

App updates (only when the release page is configured and checks are enabled): GitHub Pages (whatuneeed.github.io) serves the release metadata; GitHub hosts (github.com, objects.githubusercontent.com, release-assets.githubusercontent.com, github-releases.githubusercontent.com) serve the APK. The request reveals the TV IP address and the launcher User-Agent; no GitHub account, cookie or token is sent. Automatic checks can be changed to Manual in Settings → Device → System → Software Update, and they never run in Kids Mode. The APK is checked against its SHA-256 and the installed signing certificate; installation always uses the Android system installer.

Weather is off until you choose it. If you turn it on, the city you pick (or an approximate location derived from the internet address), the last forecast, units and source are kept locally. Turning weather off stops further weather refreshes. Settings → Weather → Clear Weather Data deletes the saved city, coordinates and last forecast immediately; otherwise the last forecast remains until it is overwritten or the app data is cleared.

Photos for the screen saver are separate from those settings: if you pick a folder or individual photos through the system picker, the launcher keeps only that read grant and the chosen URIs. It reads those images locally to draw the screen saver; they are never uploaded and are not included in a backup. The launcher does not request broad photo or storage permission, and removing the photo source releases the grant.

If you choose Reddit, the subreddit name, refresh interval, whole-or-selected mode and selected post identifiers are stored locally. The last downloaded public feed and a cache of Reddit images are also stored; Settings → Storage → Clear cache removes those caches. Reddit preferences and identifiers are not included in a backup.

Kids Mode stores a salted PBKDF2 hash of its PIN, a recovery hint and hash, the app allowlist and lockout state. The PIN itself is never stored. The recovery hint and app names are stored in plain text inside the app's private storage.

The launcher reads the list of installed apps and the public TV provider rows (Watch Next / Preview Programs) to draw Home and the recommendation shelf. Those lists are not uploaded. It also keeps the last uncaught crash trace in its private cache: the thread name and stack trace, limited to 32 KiB. The trace is never uploaded and can be removed with Settings → Storage → Clear cache.

Network requests

No account, cookie, API key or advertising identifier is sent. Like any internet request, a request reveals the TV's IP address and ordinary connection details to the host that receives it.

Apple's screen saver: the public Apple CDN at sylvan.apple.com supplies the aerial catalogue, still images and video clips. The videos and stills are fetched over HTTP because some TV trust stores reject Apple's certificate chain; only this public host is allowed cleartext. These requests carry no account, token or personal data beyond ordinary connection details. A few legacy clips bundle a still captured from that same clip, so no request is made for those. The catalogue refresh remains HTTPS.

Online trailers and descriptions (only when you turn them on in Settings → Recommendations): apis.justwatch.com serves JustWatch's public popular-titles chart; images.justwatch.com serves the posters and wide backdrops. Where the same title is found in an Apple chart, itunes.apple.com supplies the official preview metadata and video-ssl.itunes.apple.com serves the preview video; is1-ssl.mzstatic.com may supply a fallback poster. These details are attached to the matching recommendation card in "For You"; no separate Top Movies rail is shown. Those requests reveal the TV IP address and an ordinary launcher User-Agent; no account, API key, cookie or persistent identifier is sent. The chart is cached locally for six hours; turning online metadata off stops further requests, and Settings → Storage → Clear cache removes the cache. Muted previews play inside the launcher and may start automatically when a card is selected; Settings → Recommendations → Autoplay previews turns that off. A full trailer with sound starts only after you press OK.

Reddit (only when you choose Reddit): www.reddit.com serves a public Atom feed, and i.redd.it, preview.redd.it and external-preview.redd.it serve the images. Those requests reveal the TV's IP address and an ordinary launcher User-Agent; no Reddit account, cookie, token, vote or comment is sent. Reddit content is third-party and unmoderated: any subreddit can contain adult material. Reddit is disabled in Kids Mode.

Weather (only when you turn it on): Open-Meteo (api.open-meteo.com) supplies forecasts; MET Norway (api.met.no) and wttr.in are fallbacks. If you choose "Automatic", the launcher asks an IP-geolocation service (ipapi.co, then ipwho.is, then get.geojs.io) for an approximate city and coordinates. Those coordinates, the language and the chosen units are sent to the weather service. A city search sends the text you type to Open-Meteo's geocoding service (geocoding-api.open-meteo.com); a reverse-geocoding fallback may send coordinates to Nominatim (nominatim.openstreetmap.org). Weather is optional and can be turned off at any time.

Permissions

Internet access is used for Apple's screen saver, online trailers and descriptions, and, if enabled, weather.

Network state access is used to show the connection type and the local IP address on the Network page.

Wi-Fi state is used by the Control Center's Wi-Fi tile. Showing the Wi-Fi network name needs the narrower Wi-Fi permission on Android 13+ and fine location on older Android TV releases; Android 12–12L also require the coarse grant alongside fine. The launcher asks only when you press the tile and shows "Connected" if you decline. That grant is used for the network name, not for weather.

TV listings access is used to read the recommendation rows that TV apps publish. Without it the shelf simply has fewer cards.

The accessibility switch is optional. It lets the launcher take over the TV's Home button and open a chosen app after boot or wake. The service looks only at the package and window class that opened; it does not read the screen or anything you type.

Device admin is optional and used only to turn the screen off for Sleep and the sleep timer. Android asks for confirmation and the launcher requests only the force-lock policy.

The launcher does not request contacts, microphone, camera, calendar, SMS, call log or broad user storage/media access. Photos for the screen saver use only the folder or photos you choose in the system picker.

Third-party apps

Apps you start from Home handle their own data under their own policies. The launcher passes them the launch intent they published; it does not read their private content.

Kids Mode

Kids Mode is a local launcher filter and PIN gate. It is not Android parental control: system Settings, another Home app or a third-party launcher can still leave it, and content inside an allowed app is not filtered.

Your controls

Turn weather off, clear saved weather data, hide recommendation rows, clear discovery history, delete a profile, remove the screen-saver photo source, clear the Reddit source, or clear the app's cache. Deleting a profile removes its layout, discovery data, PIN, recovery data and allowlist. Clearing app data removes everything the launcher stored; Clear cache removes saved media and the local crash trace, not your settings.

Questions

The launcher is an open project: its network code, permission list and this page can be reviewed in the sources.
