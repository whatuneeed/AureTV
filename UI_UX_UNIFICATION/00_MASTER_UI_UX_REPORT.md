## 1. Цель

Единая визуальная система, логичная архитектура настроек, каждая кнопка выполняет своё назначение, управление только пультом, адаптация HD→4K, максимальное честное качество графики и сохранение производительности. Ориентир — tvOS/HIG; Apple не копируется механически, интерфейс остаётся самостоятельным.

## 2. Правила доказательств

- **PASS** — проверено командой или устройством, есть вывод.
- **FAIL** — дефект найден, указан файл и строка.
- **NOT TESTED** — возможности проверить не было; не считается успехом.
- **NOT IMPLEMENTED** — функции нет; имитация запрещена.
- Числа: `MEASURED` (измерено) или `UNKNOWN`. Эмулятор не выдаётся за реальный ТВ.

## 3. Ограничения владельца (действуют)

- Интерфейс RU/EN, оба языка вычитываются; терминология единая.
- Никаких стандартных Android-диалогов — свои экраны.
- Управление пультом первично; длинное нажатие и повтор — предсказуемы.
- Темы, цветовые схемы и размытие отклонены ранее: текущая тёмная система остаётся, «Liquid Glass» — только существующая градиентная имитация.
- Новые настройки не появляются без реальной функции; автоматика предпочтительнее галочек.
- Права не запрашиваются «на будущее».
- Файлы подписи и ключи tvOS не открываются.
- После прогонов — запись в `FIXES.md`, бэкап и остановка headless-эмулятора.

## 5. Исходное состояние — коротко

**Что уже хорошо.** Полный паритет RU/EN (417/417), нет фиктивных переключателей с потребителем-заглушкой, 458 тестов зелёные, производительность доведена адаптивными бюджетами, заставка не открывается под PIN-гейтом, единая механика удержания/повтора, единое кольцо фокуса, канва адаптируется по меньшей оси.

**Что требует работы.**

1. **P0 — детский режим обходится через Control Center**: «Система», «Специальные возможности», «Контроллеры» открывают системные экраны без PIN (`ControlCenter.kt:633-661`).
2. **P1 — настройки показывают устаревшие значения** после мастера или второго окна: заставка, погода, рекомендации кэшируются `remember` без `resumeTick` (`SettingsScreen.kt:495-520`).
3. **P1 — пустой OK на PIN** засчитывается как неверная попытка и приближает блокировку (`PinPad.kt:211-237`).
4. **P1 — дизайн-системы нет**: 8 рецептов кольца фокуса, 6 значений затемнения, 4 тона панелей, 12 easing, 26 размеров текста без шкалы.
5. **P1 — 4K не адаптируется**: масштаб только по ширине от 1920×1080, высота и safe area не читаются.
6. **P1 — качество графики упирается в источники**: видео заставки только 1080p, баннер приложения 400×240 растягивается на весь экран, стоп-кадр 900×580.

## 6. Стратегия

1. Сначала токены и компоненты (этап 3) — дальше каждый экран собирается из них, а не из литералов.
2. Перестройка настроек (этапы 4–5) идёт вместе с исправлением сохранения и дублей, чтобы не переносить дефекты в новую структуру.
3. Безопасность детского режима (UX-01, UX-02) — в первых правках функционального этапа, не в косметике.
4. 4K (этап 7) — после токенов: адаптивность делается на шкалах, а не заплатками.
5. Ресурсы (этап 8) — только честные оригиналы; если источник 1080p, интерфейс это не скрывает.
6. Каждый этап: юнит-тесты на новую логику, скриншоты ключевых экранов RU/EN, запись в `FIXES.md`, версия и бэкап.
