# 03 — Целевая структура настроек

Дата: 10.11.2026. Основание: `01_EXISTING_UI_AUDIT.md`, `02_INFORMATION_ARCHITECTURE.md`.

Состояние 0.4.37 (vc57): корень — 6 разделов, `PAGE_ROOT = 0` плюс 38 контентных страниц (`SettingsScreen.kt:262-300`). Две новые страницы-группы `PAGE_DEVICE_GROUP` и `PAGE_ABOUT_GROUP` — единственный прирост против исходных 37: дубль «Лицензий» убран без удаления страницы, потому что второй вход вёл в ту же `PAGE_DOC_LICENSES`. Мастер первого запуска — 9 страниц (`SetupScreen.kt:205-214`). Ни одна рабочая функция не удалена; удалены дубль значения версии, фиктивная строка «Канал обновлений» и заголовки групп.

## 5. Правила страниц

1. **Заголовок** — имя раздела, под ним одна строка описания, если она помогает; описания не дублируют заголовок.
2. **Строка** — заголовок, необязательное значение, необязательный шеврон; переключатель справа; нажатие на всю строку.
3. **Read-only** — без шеврона и без реакции на OK (кроме сценариев, где OK копирует значение: не вводим).
4. **Подтверждение** — отдельная страница с двумя действиями; фокус по умолчанию на «Отмена».
5. **Разрешения** — статус словами («Разрешено» / «Не выдано» / «Недоступно на этом устройстве»), действие ведёт в системный экран или в раздел «Разрешения».
6. **Ошибки** — своя строка состояния под заголовком, без стандартных Android-диалогов и toast-подмен.
7. **Возврат** — BACK на подстранице возвращает на родителя и восстанавливает фокус на открытой строке; BACK на корне закрывает настройки.

## 6. Проверка структуры (выполнено)

- [x] Каждая из 38 контентных страниц достижима и имеет родителя: `pageParent()` покрывает все страницы, кроме корня (`SettingsScreen.kt:660-690`); группы `PAGE_DEVICE_GROUP`/`PAGE_ABOUT_GROUP` открываются с корня.
- [x] Ни одна рабочая функция не потеряна: сверка §2, все строки живут на своих страницах.
- [x] Нет дублей входа в одну функцию: лицензии — один вход; мастер — одна строка; каталог заставок — одна страница.
- [x] Все строки RU/EN добавлены и вычитаны: словари `values/` и `values-en/` совпадают по ключам (`LanguageReturnTest`); полный обход RU/EN — 0.4.36, подписи новой структуры сверены в 0.4.37 по обоим файлам.
- [x] Все переключатели читаются обратно при возврате: `resumeTick` (S-1) + тест повторного чтения в `SettingsScreenTest`.
- [x] Навигация и фокус проходят по контракту §5: `SettingsScreenTest` 47/47 (включая возврат фокуса), ручной обход 10.11.2026: BACK из выбора заставки вернул фокус на «Заставку», BACK из «Сведений о системе» — на «Сведения», из «Лицензий» — на «Лицензии».
- [x] Инструментальные тесты покрывают переходы и возврат фокуса: `SettingsScreenTest`, `LanguageReturnTest`, `SetupScreenTest` (22/22), полный прогон 179/179.
- [x] Корень без заголовков групп: 6 строк, ни один узел не отдаёт заголовок простым текстом (тест `root_shows_six_sections_without_group_headers`).

Остаточный риск: `pageParent()` и таблица страниц дублируются вручную — при добавлении страницы легко забыть родителя; тест корня ловит это только для корневых строк. Покрытие всех страниц включено в этап 5 (аудит навигации).
