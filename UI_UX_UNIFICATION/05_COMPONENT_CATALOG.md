# 05 — Каталог компонентов

Дата: 11.11.2026. Версия: `0.4.40` (vc60). Состояние: инвентарь фактических компонентов; унификация грамматик этапа 4 выполнена (`TvResultRow`, `TvSearchField`, `TvKeyCap`), кольцо фокуса сведено в `ui/TvFocus.kt` на этапе 6, хост канвы — `ui/TvCanvas.kt` на этапе 7.

Каждая запись — реальный composable в коде, с указанием файла, назначения и поведения фокуса. Если у компонента есть известный дефект, он назван номером из реестра `01_EXISTING_UI_AUDIT.md`.

|---|---|---|---|

`CardShell` (`ui/components/CardShell.kt`) — единственный компонент, который уже является общим примитивом: рост, тень по профилю устройства, edge-light и specular для плиток Главной.

Новые общие примитивы этапа 4: `TvResultRow`, `TvSearchField`, `TvKeyCap` — все в `ui/components`, все с двумя потребителями.

## 6. Состояния, которые обязан поддержать новый компонент

1. **Покой** — читаемый без фокуса.
2. **Фокус** — белая заливка или белое кольцо; длительность `FOCUS_MS`, при Reduce Motion 0.
3. **Нажатие** — мгновенная обратная связь, не дольше 80 мс.
4. **Выключено/недоступно** — приглушённый текст, но не «мёртвая» кнопка без объяснения.
5. **Загрузка** — без скачка layout; место под изображение резервируется.
6. **Ошибка/пусто** — текст на русском и английском из ресурсов, не хардкод.

## 7. Правила для нового компонента

- Токены только из `LauncherColors`, `TvInk`, `TvRadius`, `TvOs`; hex в экране — ошибка ревью.
- Кривая движения — из `TvMetrics.kt`; локальный `CubicBezierEasing` — ошибка ревью.
- Строки — только `stringResource`; паритет RU/EN обязателен.
- Компонент не появляется без потребителя; «на будущее» — запрещено.
- Фокус и клавиши описываются в этом каталоге до реализации, чтобы не появился девятый рецепт кольца.

## 8. Известные пробелы каталога

- Закрыто этапом 6: общий контракт кольца `TvFocus` (три режима) заменил восемь реализаций.
- Закрыто этапом 4: общие `TvResultRow`, `TvSearchField`, `TvKeyCap`.
- Закрыто этапом 5: `WeatherPanel` действует по OK (закрытие, UX-10); точки полки — индикатор (UX-11); системные плитки Control Center и папка подчиняются детскому PIN (UX-01, UX-02).
- Закрыто этапом 6: кольцо фокуса — контракт `TvFocus`, восемь рецептов сведены к трём режимам.
- Закрыто этапом 7: раскладка хоста — `TvCanvas` по меньшей оси, safe area и центрирование; поля 50/90 pt сведены к `SAFE_AREA`/`DOCK_BLEED` (документ 13).
- Снято как ошибка аудита: «нет общего `TvButton`» (второго потребителя нет), «переключатель читается как разные функции» (роли разные), «диск профиля — градиент против плоского» (обе заливки плоские, грамматика уже общая).
