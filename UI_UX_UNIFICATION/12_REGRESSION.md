### 3.7 Поиск

`59_search_overlay`, `42_search_youtube.png`: SEARCH открывает оверлей с полем и клавиатурой; запрос `you` даёт «YouTube» и «YouTube Music» в разделе «Apps». BACK возвращает на Главную с прежним фокусом.

**Наблюдение (не дефект этапа).** Запрос `kin` не находит «Кинопоиск» и «КиноТрек»: `searchApps` сравнивает по `lowercase(Locale.ROOT)` без транслитерации (`AppSearch.kt:53-54`), а имена приложений — кириллицей. Поиск по латинице работает только там, где латиница есть в самом имени. Требование транслитерации нигде не заявлено; поведение зафиксировано, решение за владельцем.
