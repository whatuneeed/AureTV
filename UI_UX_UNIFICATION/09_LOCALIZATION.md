## 1. Как работает язык

- Язык хранится в общих настройках (`ovisiontv_launcher.xml`, ключ `ui_language`: `system` / `ru` / `en`) — `data/LocalePreference.kt:12-38`. Встроенный механизм «язык приложения» появился только в API 33, а `minSdk = 28`, поэтому выбор применяется обёрнутым контекстом `createConfigurationContext`.
- Все три активности оборачивают базу: `MainActivity.kt:66-67`, `SettingsActivity.kt:30-31`, `SetupActivity.kt:31-32`. Compose читает `LocalConfiguration` уже из этого контекста, поэтому смена языка перестраивает весь экран, включая `stringResource`.
- «Системный» означает системную локаль устройства. Каталог `values/` — английский, `values-ru/` — русский; для любой другой системной локали интерфейс остаётся английским (запасной каталог), без «полуперевода».
- Строк в каждом каталоге: **414** `<string>`, **4** `<plurals>`, **1** `<string-array>` (MEASURED: `grep -c` по обоим файлам, 11.11.26).

## 2. UX-12 — подзаголовки мастера без ограничения строк

**Было.** Текст подзаголовка страницы мастера не имел ни ширины, ни `maxLines`: длинная русская фраза растягивала абзац и выдавливала кнопки за нижнюю границу кадра.

**Стало** — `ui/SetupScreen.kt:148,151,893-895`:

```kotlin
private const val SUBTITLE_WIDTH = 1040f
private const val SUBTITLE_LINES = 4
...
lineHeight = scale.sp(current.subtitleFont * 1.15f),
maxLines = SUBTITLE_LINES,
overflow = TextOverflow.Ellipsis,
modifier = Modifier.width(scale.dp(SUBTITLE_WIDTH)),
```

Ширина 1040 pt — уже текстовой колонки страницы, поэтому перенос случается раньше кнопок. Четыре строки с межстрочным 1,15 сохраняют читаемость и оставляют кнопки в кадре. Проверено на широких фразах RU и EN: `screenshots/stage10-0.4.42/04-profile-ru.png`, `13-profile-en.png` — подзаголовок занимает две строки, кнопки «Назад/Далее» видны целиком.

**Регрессия 0.4.43.** Сводка на последней странице мастера — тоже подзаголовок, и она состоит из четырёх строк (язык, полка, заставка, погода). При `SUBTITLE_LINES = 3` четвёртая строка обрезалась многоточием на обоих языках; лимит поднят до 4. Проверено кадрами `screenshots/stage11-0.4.43/10_finish_fixed.png` (RU, «Погода: по интернет-соединению» целиком) и `40_finish_en.png` (EN, «Weather: over the internet»); самые длинные подзаголовки страниц по-прежнему укладываются в 2–3 строки.

## 3. UX-21 — терминология RU/EN

| Понятие | EN | RU | Почему |
|---|---|---|---|
| Видео заставки | clip | **ролик** (не «клип») | «клип» — калька; слово унифицировано во всём каталоге: `saver_preview_hint`, `saver_refresh`, `settings_last_clip_hint`, `settings_clips_empty`, plurals `settings_clips_count` |
| Заставка как экран | **Screen Saver** (не «Screensaver») | Заставка | одна запись в `cc_screensaver`; раньше встречалось «Screensaver» |
| Частота загрузки роликов | Download Frequency | Частота загрузки роликов | «Обновлять ролики» — глагол вместо существительного, заменено |
| Недоступно на ТВ | Not available on TV | Недоступно на телевизоре | без кальки «не поддерживается» |
| Максимум/минимум погоды | H: 4° L: 2° | Макс.: 4° Мин.: 2° | H/L ничего не говорят по-русски; добавлена `weather_high_low` с подстановкой подписей |

Регрессия закреплена `data/LocalizationTest.kt`: совпадение имён ключей, совпадение плейсхолдеров, запрет «клип» в RU, запрет «creensaver» и «Обновлять ролики». Прогон — §6.

Явные границы: названия контента (фильмы, приложения), бренды («MET Norway», «Google Play», «Кинопоиск») и подпись службы доступности не переводятся.

## 4. UX-22 — хардкод строк и форматов

**Часы.** Время Главной, Control Center, погоды и мастера идёт по языку интерфейса, а не по системной локали (система на стенде ru-RU, поэтому EN-кадры это доказывают): `ui/components/WeatherText.kt:16-19` — `H:mm`/`H` для `ru`, `h:mm a`/`h a` для `en`; вызывается из `ControlCenter.kt:223-226`, `weatherTimeLabel` и `weatherHourLabel` (там же :47-64), мастер — `SetupScreen.kt:1129`. Зафиксировано `LocalizationTest.clockFollowsTheInterfaceLanguage`.

**Числа.** Размеры и проценты печатаются локалью экрана, а не системной: `SettingsScreen.kt:424-426` (`formatLocale` из `LocalConfiguration`) и `data/DeviceFacts.kt:188-198` (`DeviceFormat.size`); иначе русский интерфейс на английской системе показывал бы `1.5 MB`.

**Погода.** Подписи условий — WMO → ресурсы (`WeatherText.kt:27-43`), часы и подпись «снято в» — по языку (`:47-64`), дни недели — `EE` с обрезкой точки, регистр по языку (`:68-79`), единица ветра — `км/ч`/`km/h` (`data/Weather.kt:156-157`). Неизвестный код погоды молчит, а не выдумывает состояние.

**Машинные форматы — намеренно нейтральные.** Разбор ISO-дат и время запросов к провайдерам погоды фиксируются `Locale.US` (`data/Weather.kt:318,358,372-374,448,469,565-566`): это протокол, а не текст для пользователя. Ожидание блокировки PIN форматируется `Locale.ROOT` (`PinPad.kt:481,610`).

**Имена по умолчанию.** Папка по умолчанию и скрытая папка берутся из ресурсов через обёрнутый контекст (`data/HomeOrderStore.kt:21-27`), захардкоженного «Folder» больше нет. Имя стартового профиля — `profile_default_name` («Me» / «Я»).

**Что осталось литералом осознанно:** `°`, разделитель ` · `, длинное тире `—` для пустого значения (`DeviceFacts.kt:94,177,213`, `SettingsScreen.kt:1561,3722,3805`), грани клавиш `OK`, `⌫`, `⇧`, `abc`, `абв`, `123` (это имена наборов символов, а не слова; для TalkBack рядом лежит локализованное описание — `TvKeyboard.kt:231-261`), единица `Hz`, приветственный тур мастера «Добро пожаловать / Bienvenue / …» (`SetupScreen.kt:1046-1049`), а также названия источников и брендов.

## 5. Найденный и исправленный дефект этапа

**Симптом.** При английском интерфейсе строка «Name» в мастере показывала «Я»: кадр `screenshots/stage10-0.4.42/13-profile-en.png`.

**Причина.** `ProfileStore` брал `context.applicationContext` без языковой обёртки и читал `profile_default_name` по системной локали (ru-RU). `LocalizationTest` ловил рассинхрон ключей, но не подмену контекста.

**Исправление.** `data/Profiles.kt:265-275`: `private val appContext = LocalePreference.wrap(context.applicationContext)`; имя по умолчанию и ремонт старого значения идут через этот контекст. В EN мастер и Настройки показывают «Me» — `14-after-restart.png`, `27-settings-en.png`; в RU — «Я» (`04-profile-ru.png`). Поведение разбора закреплено `ProfilesTest.placeholderNameFollowsTheInterfaceLanguage`; сама обёртка контекста проверена только на устройстве (юнит-тест не создаёт `Context`).
