Стенд: `hume-tv`, AOSP TV x86, API 34, `1920×1080`, 320 dpi, SwiftShader, система ru-RU. Все числа — `MEASURED` на нём. Реальный ТВ, другие API и плотности не выдаются за проверенные.

## 1. Версии Android

| Параметр | Значение | Источник |
|---|---|---|
| `minSdk` | 28 (Android 9) | `app/build.gradle.kts:27` |
| `targetSdk` / `compileSdk` | 35 | `app/build.gradle.kts:23,28` |
| Проверено на | API 34, x86 | `ro.build.version.sdk`, `ro.product.cpu.abi` |
| API 28–33, 35 | **NOT TESTED** | отдельного стенда нет |

Почему API 28 выбран минимумом: лаунчеру нужны Compose, `AccessibilityService` и device admin — всё доступно с 21–26; API 28 отсекает телевизоры без современных media-кодеков. Встроенный механизм «язык приложения» (API 33) не используется — язык работает через `createConfigurationContext` (`data/LocalePreference.kt:28-34`), поэтому запрет на API < 33 отсутствует.

Версионные ветки в коде:

- `Build.VERSION.SDK_INT < Q` — тепловой статус недоступен, профиль производительности берётся по умолчанию (`data/AdaptivePolicy.kt:136`, `ui/LauncherRoot.kt:266`);
- `SDK_INT >= 33` — приём `ACTION_SCREEN_ON` регистрируется с `RECEIVER_NOT_EXPORTED` (требование Android 13+), на 28–32 — старый вызов (`OVisionAccessibilityService.kt:40-44`);
- `API 30+` — видимость системного TV-провайдера через `<queries><provider android:authorities="android.media.tv"/>` (`AndroidManifest.xml:65-67`).

## 2. Классы устройств и ввод

- Основное устройство — Android TV (leanback). Обязательных `uses-feature` нет: `leanback`, `touchscreen`, `wifi`, `location`, `location.gps` помечены `required="false"` (`AndroidManifest.xml:6-22`), поэтому APK ставится и на телефон для разработки и кадров. Это осознанно, а не поддержка телефона как продукта.
- Управление только пультом: стрелки, OK, BACK, удержание OK; экранная клавиатура и PIN-планшет не требуют касаний. Длинное нажатие на эмуляторе имитируется `adb emu event` — аппаратный автоповтор ИК-пульта на реальном ТВ **NOT TESTED**.
- TalkBack: разметка и семантические действия есть, но полная голосовая приёмка отложена отдельным решением; UI-тесты гоняются с выключенным TalkBack из-за гонки Compose/accessibility.
- Ориентация зафиксирована `landscape` у трёх активностей; смена `density`/`screenSize` обрабатывается через `configChanges`, поэтому пересоздания при смене режима экрана нет.
- Тач-жесты, мышь и геймпад не поддерживаются и не обещаются.

## 4. Разрешения и системные доступы

| Разрешение | Тип | Когда просится | Если отказано |
|---|---|---|---|
| `INTERNET`, `ACCESS_NETWORK_STATE` | обычные | при установке | без сети — полка, погода и заставка без онлайн-роликов |
| `READ_TV_LISTINGS` | опасное | мастер (один раз) / строка в Настройках | полка остаётся пустой с честной подписью |
| `ACCESS_WIFI_STATE` | обычное | при установке | плитка Wi-Fi показывает «Подключено» |
| `ACCESS_COARSE_LOCATION`, `ACCESS_FINE_LOCATION` | опасные | из плитки Wi-Fi или строки геопогоды, по действию | имя сети/город не показываются, экран не ломается |

Разрешения «на будущее» не запрашиваются: уведомления, фоновая геолокация, автозапуск и спец. возможности не добавляются. Служба доступности включается только вручную в системных настройках ТВ; device admin активируется системным экраном с пояснением. Оба пути — системные экраны, приложение их не обходит.

## 5. Сеть и TLS

- Клиренс-текст запрещён базовой конфигурацией; единственное исключение — `sylvan.apple.com` (ролики заставки; в РФ порт 443 к CDN Apple закрыт, порт 80 отдаёт те же файлы) — `res/xml/network_security_config.xml`. Правило закреплено `NetworkSecurityConfigTest` (2 теста).
- Погода: `api.open-meteo.com`, `api.met.no`, `wttr.in`, геокодинг `ipapi.co` / `ipwho.is` / `get.geojs.io` / `nominatim.openstreetmap.org` — всё по HTTPS (`data/Weather.kt:297,359,427,588-590,628`). Пользовательские данные не отправляются; запросы идут по координатам или IP-адресу устройства.
- Сеть может быть только Ethernet — Wi-Fi не требуется (`AndroidManifest.xml:12-16`).

## 6. ABI, размер, хранение

- Код — Kotlin/JVM; единственная нативная библиотека — `libandroidx.graphics.path.so` (зависимость Compose), поставляется для `arm64-v8a`, `armeabi-v7a`, `x86`, `x86_64`. Стенд x86-32 запускается.
- Release APK: **4 061 318 B**, SHA-256 `a0717c3d54a68d84ea521f51b3c774dbaa903ef7f6b1fe243821ff3e4bb2a4f2` (MEASURED, `sha256sum`).
- `allowBackup="false"` + `dataExtractionRules`/`backup_rules`: раскладка, профили, PIN и настройки не уезжают в облачный бэкап (`AndroidManifest.xml:71-74`).
- Дисковый кэш заставки ограничен бюджетом профиля устройства; при нехватке места ролики играются онлайн, без диска.

## 7. Языки, регионы, RTL

- Каталоги `values` (EN) и `values-ru` (RU); язык интерфейса не зависит от системного, но «Системный» следует за ним. Для прочих локалей интерфейс английский.
- Валюта, часовой пояс, названия дней недели и числа берутся из локали экрана (`09_LOCALIZATION.md` §4).
- `supportsRtl="true"` включён, но RTL-языки не поставляются и RTL-раскладка **NOT TESTED**; продукт двуязычный по решению владельца.
