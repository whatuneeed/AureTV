# GitHub release kit — AURE TV 0.6.0

Этот каталог содержит материалы для страницы GitHub Release. Публикация APK
выполняется только после отдельного разрешения владельца.

## Состав

| Файл | Назначение |
| --- | --- |
| `RELEASE_NOTES_0.6.0.md` | текст релиза на английском |
| `RELEASE_NOTES_0.6.0.ru.md` | текст релиза на русском |
| `screenshots/00-cover.png` | обложка AURE TV |
| `screenshots/01…10*.jpg` | полноразмерные скриншоты 1920×1080 |
| `AURE-TV-0.6.0.apk` | готовый подписанный APK (не коммитится; см. `.gitignore`) |
| `CHECKSUMS.txt` | SHA-256 и имя APK |
| `AURE-TV-0.6.0.apk.sha256` | та же сумма в формате `sha256sum` |

Основная страница репозитория — `README.md` в корне; русская версия —
`README.ru.md`. В них уже вставлена галерея из `screenshots/`.

## Как опубликовать

1. Создать репозиторий GitHub и отправить туда коммиты и теги.
2. Открыть **Releases → Draft a new release**.
3. Указать тег `v0.6.0`, заголовок `AURE TV 0.6.0`.
4. Вставить текст из `RELEASE_NOTES_0.6.0.md` или
   `RELEASE_NOTES_0.6.0.ru.md`.
5. Приложить к релизу `AURE-TV-0.6.0.apk` и `CHECKSUMS.txt`.
6. При желании приложить скриншоты как assets; для README они уже лежат в
   `GITHUB_RELEASE/screenshots/`.
7. Проверить, что asset называется `AURE-TV-0.6.0.apk`, а SHA-256 совпадает с
   `df6b96724c3feeef1d6025fc5046a0c890cedacbd89adba04ca5f266639b120a`.
8. **Не нажимать Publish без разрешения владельца.**

## Важно

- Пакет `app.aure.tv` — новое приложение, а не обновление
  `com.whatuneed.ovisiontv.kotlin`. Это нужно явно указать в описании релиза.
- Это первый публичный релиз; физический Android TV, 4K/HDR, реальный пульт и
  TalkBack ещё не проверены. Не убирать этот дисклеймер из release notes.
- В сборке не настроен канал обновлений; не обещать автоматические обновления.
- Flux не входит в APK. Рекомендации на скриншоте — реальные строки TV
  provider, опубликованные установленными приложениями.
