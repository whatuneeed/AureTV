## Проверка перед публикацией

1. Убедиться, что release gate прошёл для текущего APK.
2. Не коммитить `docs/update.json` с 0.6.2 до появления релиза: иначе старые
   клиенты получат ссылку на ещё не существующий asset. Сейчас в рабочем
   каталоге оставлен опубликованный 0.6.1.
3. Создать тег `v0.6.2` и GitHub Release, прикрепить APK и `CHECKSUMS.txt`.
4. После публикации workflow `publish-update.yml` обновит `docs/update.json`
   на 0.6.2; только тогда встроенный updater увидит новую версию.
5. Проверить скачивание APK по HTTPS, совпадение SHA-256 и то, что
   `docs/update.json` содержит `versionCode 156`.

## Важно

- 0.6.0 не умеет обновлять себя; 0.6.1 — первая сборка с каналом обновлений.
- APK подписан тем же ключом, который нужен для будущих обновлений.
- Физический Android TV, реальные пульты, 4K/HDR и TalkBack по-прежнему
  остаются непроверенными.
