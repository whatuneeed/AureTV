# AURE TV 0.6.2

Сервисное обновление стабильности. Новых функций лаунчера в нём нет.

## Что изменилось

- **Отмена резервного копирования больше не превращается в ложную ошибку.**
  При уходе с экрана Backup `CancellationException` пробрасывается дальше, а
  не обновляет уже уничтоженный экран. Отменённое восстановление по-прежнему
  откатывает частично применённые данные, после чего сохраняет отмену.
- **Поиск Home-приложений больше не удерживает блокировку во время запроса
  PackageManager.** Accessibility-служба выполняет запрос вне блокировки
  публикации и атомарно заменяет снимок кеша. Поток событий не ждёт медленное
  сканирование пакетов.
- **Более строгая проверка заголовков шифрования backup.** Архив должен
  содержать соль ровно 32 байта и nonce 12 байт; слишком длинные Base64-
  параметры отклоняются до декодирования и PBKDF2.
- **Канал обновлений не может незаметно откатиться назад.** Генератор
  метаданных не принимает старый `versionCode` или повтор той же версии с
  другим APK, а workflow требует ровно один APK в релизе.
- **CI теперь собирает и проверяет release-вариант** вдобавок к debug lint и
  JVM-тестам.
- **Документация обновлений исправлена.** Канал использует HTTPS, строгий
  allowlist хостов, SHA-256 и сверку подписи APK; сам JSON метаданных больше не
  называется криптографически подписанным.
- Версия **0.6.2** (`versionCode 156`), подписана тем же ключом.

## Установка

Требования: Android TV 9+ (API 28). Для самого лаунчера аккаунт Google не нужен.

```bash
adb install AURE-TV-0.6.2.apk
```

Сборки начиная с 0.6.1 смогут обновиться из
**«Настройки → Устройство → Обновление ПО»** после публикации релиза. Метаданные
не записываются до публикации.
