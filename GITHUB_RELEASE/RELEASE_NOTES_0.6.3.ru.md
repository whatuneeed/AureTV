# AURE TV 0.6.3

Горячее исправление разрешения на установку внутри приложения.

## Что изменилось

- **Возврат из системных настроек неизвестных источников сразу обновляет
  экран.** Экран обновления заново читает `canRequestPackageInstalls()` по
  `ON_RESUME`, а не ждёт изменения состояния, которого не было. После выдачи
  разрешения кнопка установки появляется без выхода и повторного входа в
  **«Настройки → Устройство → Обновление ПО»**.
- **Устаревшее приглашение выдать разрешение убирается.** Экран переключается
  с «Разрешить установку» / «Открыть настройки установки» на
  «Готово к установке» и переводит фокус на **«Установить обновление»**.
- **Установка по-прежнему требует системного подтверждения.** AURE TV ничего
  не устанавливает молча.
- Версия **0.6.3** (`versionCode 157`), подписана тем же ключом.

## Проверка

- JVM unit-тесты: **588 / 588**, 0 failures, 0 errors, 0 skipped
- Android lint: **0 ошибок, 16 предупреждений**
- Release APK: `app.aure.tv`, **0.6.3** (`versionCode 157`), APK Signature
  Scheme v2, тот же сертификат подписи
- Release gate: пакет, SDK, подпись v2, сертификат и совпадение RU/EN-ресурсов
  проходят
- Эмулятор: release-сборка **0.6.1 (155)** скачала опубликованную **0.6.2**,
  открыла настройки неизвестных источников, и после возврата сразу показала
  **«Установить обновление»**. Системный диалог успешно установил
  **0.6.2 (156)**.
- Финальный APK **0.6.3 (157)** установлен поверх 0.6.2 и запускается; экран
  обновления показывает 0.6.3 (157).
- Обновление **с 0.6.2 на 0.6.3** внутри приложения пока **не проверено**:
  на момент заметок 0.6.3 не опубликована.

Физический Android TV, реальные пульты, 4K/HDR и TalkBack остаются
непроверенными. Результат эмулятора не заменяет проверку в гостиной.

## Установка

Требования: Android TV 9+ (API 28). Для самого лаунчера аккаунт Google не нужен.

```bash
adb install AURE-TV-0.6.3.apk
```

Сборки начиная с 0.6.1 смогут обновиться из
**«Настройки → Устройство → Обновление ПО»** после публикации релиза.
