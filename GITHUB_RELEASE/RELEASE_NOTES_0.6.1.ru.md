# AURE TV 0.6.1

Сервисное обновление: включает встроенный канал обновлений.

## Что изменилось

- **Встроенные обновления теперь настроены.** Сборки начиная с 0.6.1 проверяют
  подписанные метаданные релиза по адресу
  `https://whatuneeed.github.io/AureTV/update.json`.
- Метаданные создаются из APK, прикреплённого к опубликованному GitHub-релизу.
  Без совпадения размера и SHA-256 файл не считается доверенным.
- Загрузка идёт только по HTTPS и только с документированных хостов GitHub;
  финальную установку подтверждает системный PackageInstaller. Тихих
  обновлений нет.
- **Политика конфиденциальности версии 12** называет хост метаданных GitHub
  Pages и все хосты загрузки APK.
- Версия **0.6.1** (`versionCode 155`), подписана тем же ключом.

## Важно

Опубликованная сборка 0.6.0 выпущена до появления канала и не умеет обновлять
себя. Один раз установите 0.6.1 вручную; последующие версии можно ставить из
**«Настройки → Устройство → Обновление ПО»**.

## Проверка

- JVM unit-тесты: **583 / 583**
- Release APK: `app.aure.tv`, **0.6.1** (`versionCode 155`), подпись
  APK Signature Scheme v2
- Экран обновления проверен на эмуляторе Android TV `hume-tv` (API 34, x86,
  1920×1080): источник настроен, ручная проверка проходит
- Полный цикл загрузки и установки нового опубликованного APK: **пока не
  проверен**

Физический Android TV, реальные пульты, 4K/HDR и TalkBack остаются
непроверенными.

## Установка

Требования: Android TV 9+ (API 28). Для самого лаунчера аккаунт Google не нужен.

```bash
adb install AURE-TV-0.6.1.apk
```
